# POI Search Management 

Frontend module for searching, viewing, selecting, and adding Points of Interest to a trip.

## Features

- Search POIs and view search history
- Display POI details and map locations
- Select multiple POIs
- Add POIs to a selected Trip and Day
- View added POIs in My Trips
- Filter results by category and rating

## Run

```bash
cd tp_frontend
npm install
npm start
```

## Current Data Source

The module currently uses Shanghai mock data and browser local storage. Backend API and Google Places integration will be added later.
